# Patchbay Studio

A music production app (DAW) that runs entirely in the browser: arrangement and Session views, piano roll with scales and chords, instruments and effects with 1,400+ presets, a sample library, mixer with sends and a master limiter, MIDI keyboard support, and a phone layout.

**Open it:** https://benjaminbencsik.github.io/patchbay-studio/

Everything is one file, `index.html`. Projects are saved in your browser; use File ▸ Save to keep a copy as a file.
